## Remaining issues and prerequisites

- issue_runtime [unresolved; full_pipeline, analysis_only]: MATLAB and the source-used toolbox/functions could not be verified in the target environment: the MATLAB executable did not resolve on PATH and no license/toolbox probe was possible.
- issue_custom_helpers [blocking; full_pipeline]: The supplied inventory has no definitions for README-required cluster_se.m and cluster_wildboot.m, which active simulation source calls. The current closure of these helpers is unresolved.
- issue_frlag [unresolved; full_pipeline]: FRQSim_EstAR actively calls FRQlag for its own lag construction; no FRQlag definition is supplied among the package's MATLAB sources. Do not assume FRQLagGroupMean is an alias.
- issue_numtolatex [blocking; full_pipeline, analysis_only]: README-listed NumToLatex.m is absent from the supplied inventory, while FRQSim_MBB_Power calls NumToLatex to format results.
- issue_finalstats [blocking; full_pipeline]: README's ordered workflow requires FRQSim_FinalStats.m for most main-paper and supplement summaries, but the file is not supplied. FRQSim_FinalStats_Gauss.m is a separate Gaussian-critical-value summary and does not replace this stage.
- issue_root_paths [preparation; full_pipeline]: The documented workflow says directory references must be modified; source scripts contain fixed Windows directory literals. A consistent package root and working-directory setup must be selected across producing and consuming stages.
- issue_mbb_handoff [preparation; full_pipeline]: MBB1–4 save each simulation MAT under Results/Pt1–Pt4, but the four wrap-up scripts load the same basename from the current directory. The packaged result MATs are at the archive root. The run handoff path must be reconciled consistently, and output folders may need creation.
- issue_mbb_power_paths [preparation; full_pipeline, analysis_only]: FRQSim_Main writes FRQSim_FINAL_PART1 in its current directory, while FRQSim_MBB_Power reads it under Results/Chris; MBB_Power also reads Pt2–Pt4 beneath Results/PtN although the supplied final MATs are at the archive root. Full-pipeline and packaged-result analysis routes need distinct coherent path choices.
- sw_matlab [unverified]: README requires MATLAB. A bounded PATH probe found no `matlab` executable; installation and license state were not inferred.
- sw_stats [unverified]: Verify Statistics and Machine Learning Toolbox functions used by this scope, including dummyvar, grpstats, prctile, tinv, histfit, tpdf and fitdist; the MATLAB runtime was not available for a toolbox probe.
- sw_optim [unverified]: FRQFitModel calls fmincon; verify MATLAB Optimization Toolbox availability in the target runtime.
- sw_parallel [unverified]: FRQSim_WildBoot calls parpool and pctRunOnAll; verify the parallel functions/toolbox in the target runtime.
