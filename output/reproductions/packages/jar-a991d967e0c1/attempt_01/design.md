SAS imports only the first worksheet through `PROC IMPORT`, retains rows with a nonmissing participant code, maps `PresentationFormat` to `presentation`, and keeps the six analysis variables plus a temporary sequential row index. The workbook's participant code is not carried into the exported analysis file. Blank trailing worksheet rows are omitted; the blank extra trailing header is not used.

The main analyses require the supplied match outcome, link ratio, nonlink ratio, presentation group, experience, and gender; all 60 participant rows have these fields observed.

## Estimators and source alignment

**H1, main paper Table 5, p. 138.** Define the above-mean group as `LinkFixationRatio > sample mean`; the below-mean group is `< sample mean`. There are no ties at the mean in this workbook, and the groups contain 33 and 27 participants. Following the paper and author data-description sheet, run separate one-sample Pearson chi-square goodness-of-fit tests of equal consistent/inconsistent decisions within each group. The expected frequency in each of the two outcome cells is half of that group's size (16.5 and 13.5, respectively). This reproduces the authors' manual 50:50 test and does not use the conventional 2×2 independence test.

**H2/H3, main paper Table 6, p. 139.** Use the workbook's `LinkFixationRatio` and `NonLinkFixationRatio` as the two within-subject levels of favored measure. Fit a repeated-measures mixed ANCOVA with presentation format (three categories) between subjects, working experience as a continuous covariate, and gender as the numeric 0/1 covariate used in the author-described procedure. The source-reported effects are measure, presentation, experience, gender, measure×presentation, measure×experience, and measure×gender. For the Stata implementation, the between-subject effects are estimated on each participant's mean of the two supplied ratios; the measure main effect and measure interactions are obtained from Stata's long-form repeated-measures `anova`. This two-level decomposition is exact for the complete paired sample and yields the marginal between-subject tests rather than tests at the base repeated-measure level. Participant is nested within presentation for the repeated model's between-subject error term; partial sums of squares are used.

The data-description sheet calls the procedure “Full Factorial” but does not specify the SPSS model dialog or all terms. The manuscript Table 6 reports the seven effects above; it does not display higher-order presentation×covariate terms. The implemented specification follows the reported Table 6 rows. Exact historical SPSS syntax and the workbook's Excel-import behavior remain unavailable, and SPSS 22 has not been used to verify software equivalence.

**Online Appendix Table A1.** As a separate supplementary result, define above/below median groups using the supplied link ratio and run the same within-group 50:50 goodness-of-fit chi-square tests. No observations tie at the median; the groups contain 30 participants each. This is not substituted for the primary mean split.

## Execution and fidelity limits

SAS performs workbook import, sample-field preparation, aggregate input diagnostics, and export to a private Stata data file. Native Stata 18 runs the chi-square calculations and repeated-measures ANCOVA. The notebook follows `skills/reproduce-accounting-models/references/stata.template.ipynb`'s self-contained cell pattern and contains no custom Stata program or Mata code.

Replay requires a private working copy with the source-package workbook copied to `input/chen-et-al-dataset.xlsx` after verifying the SHA-256 above. Create writable `data/`, `logs/`, `tables/`, and SAS work directories before running the portable commands in `README.md`. Do not publish the input workbook, private analysis `.dta`, or native logs.

The publication tables and result record contain aggregate counts and test statistics only. The participant-level workbook copy, intermediate `.dta`, SAS/Stata logs, and raw identifiers remain in the private build directory and must not enter the review publication allowlist. The source Table 6 mean-square column contains an internal arithmetic inconsistency for the measure×presentation row as rendered in the accessible text (MS 0.12, F 0.21, residual MS 0.05). Fidelity claims therefore compare the reported F statistics, degrees of freedom, p-values, and sample size, not every displayed mean-square value.
