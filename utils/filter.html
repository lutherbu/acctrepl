Filter whole papers, not their source lists

A paper qualifies only when it has recorded data sources and every source across all its samples is checked. One unchecked source excludes the entire paper.

Papers marked no_empirical_sample, papers with no recorded sources, and papers with incomplete sample-source metadata are excluded automatically.

Selection uses the extraction’s recorded information; it does not verify actual access. Names are kept as written, without guessing which differently named sources are equivalent.
